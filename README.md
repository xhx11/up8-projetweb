# Artist Rooms Paris

This project was developed as part of a university web development course.

The objective was to design and implement a website for **Artist Rooms Paris**, an organization dedicated to supporting and promoting international artists.

The project includes:

- Responsive web pages (HTML/CSS)
- PHP features and contact forms
- Accessibility considerations
- UI/UX design with Figma
- English and French versions of the website
- Dynamic artist management system

This repository contains the source code used for the project.
